# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 0.1.0 - 2026-08-30

### Added

- Strict versioned JSON plans with exact `Decimal` dimensions.
- Complete per-job shim-combination enumeration.
- Exact global allocation across finite shared stock.
- Worst-case symmetric-tolerance proof and stable optimization.
- Explicit `SHS101`, `SHS102`, and `SHS199` outcomes.
- Deterministic JSON, CSV, Markdown, and standalone HTML reports.
- Feasible and shared-stock-conflict examples plus installed `demo` command.
- Cross-platform CI, isolated wheel acceptance, release automation, and Pages report deployment.
